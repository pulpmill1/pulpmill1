# pulpmill1

Single-file production dashboard for Pulp Mill 1 / Fiberline 1.
Live-fetches the "Data Base Fiberline 1" Google Sheet client-side — no build step.

- **Live:** https://pulpmill1.vercel.app
- **Deploy:** auto-deploys to Vercel on every push to `main`.
- Source: `index.html` (self-contained). `vercel.json` = static config.
